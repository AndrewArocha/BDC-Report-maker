# BDC Report Generator

This was the first prototype for a reporting tool for automotive Business Development Center (BDC) teams. It explored how dealership staff could organize daily activity and turn same-day and next-day appointments into a report formatted for WhatsApp.

**The project continued as [EVEO BDC](https://github.com/AndrewArocha/project-eveo-bdc).** EVEO expands the original idea into a full-stack dealership platform with sign-in, persistent records, and workflows for leads, appointments, and showroom activity. It’s in active development and has a [staging preview](https://project-eveo-bdc-stage.vercel.app/).

## Original prototype

Built with HTML, CSS, and vanilla JavaScript. The forms are visible, but the active script still has placeholder actions for adding appointments, generating reports, and copying output.
